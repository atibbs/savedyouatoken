# Community support

savedyouatoken Community is maintained on a best-effort basis. There is no guaranteed response,
resolution, compatibility, or release timeline.

- Read the repository documentation for setup and product behaviour.
- Use the question issue template for usage questions and implementation ideas.
- Use the issue templates for reproducible bugs and bounded feature requests.
- Use the private channel in [`SECURITY.md`](SECURITY.md) for vulnerabilities.

Public support covers the current analysis engine, CLI, SDK, local-first web analyser, agent kit,
and shared contracts. It does not cover bespoke prompt optimization, private deployments, old
versions, modified forks, provider billing disputes, or the planned hosted Monitor service.

Never post real prompts, credentials, production reports, customer data, or other confidential
information when requesting help. Reduce a problem to a synthetic reproduction first.
