# Governance

savedyouatoken uses a lightweight maintainer model. Andrew Tibbs (`@atibbs`) is the current lead
maintainer and has final responsibility for product direction, repository access, releases,
security decisions, and the Community/hosted boundary.

Contributors influence the project through issues, discussions, design proposals, code review, and
pull requests. Maintainers evaluate changes for user value, correctness, privacy, compatibility,
maintenance cost, and alignment with the roadmap. Consensus is preferred, but the lead maintainer
makes the final decision when consensus is unavailable.

Repository write access may be offered to sustained contributors who demonstrate sound judgment,
respect the code of conduct, protect user data, and consistently review or maintain an area. Access
can be narrowed or removed to protect the project.

Community governance covers the public analysis and instrumentation software. It does not grant
authority over hosted Monitor operations, commercial terms, customer data, private infrastructure,
or the private control-plane repository.

This model should be revisited when contributor scale, funding, legal obligations, or maintainer
availability make a broader structure useful.
