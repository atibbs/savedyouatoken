# @savedyouatoken/core

The dependency-free analysis engine and versioned report, baseline, and policy contracts used by
the savedyouatoken web analyser, CLI, and runtime SDK.

The package performs deterministic local analysis and makes no network or model calls. Its source is
primarily consumed inside the savedyouatoken workspace; public contracts are available through the
`./contracts/*` exports.

Architecture and methodology documentation is available at
<https://savedyouatoken.com/methodology>. Source, issues, and contribution instructions live in the
[savedyouatoken repository](https://github.com/atibbs/savedyouatoken).
